# Išmokų skaičiuoklės

Dvi skaičiuoklės, palyginančios, kiek asmeniui lieka į rankas, kai priklausanti suma išmokama per darbo užmokestį, mažąją bendriją (MB) ar individualią veiklą (IV). Antroje skaičiuoklėje papildomai įvertinami dividendai pagal privilegijuotas akcijas.

- `index.html` – pradinis puslapis su nuorodomis
- `skaiciuokle.html` – DU, MB ir IV palyginimas
- `skaiciuokle-akcijos.html` – tas pats su privilegijuotų akcijų dividendais

Skaičiuoklės veikia naršyklėje, be serverio. Įvesti duomenys saugomi tik naudotojo naršyklėje.

Skaičiavimai yra informacinio pobūdžio ir nėra mokesčių konsultacija.
